# Procedimento: Defeito de Superfície

## Identificação
Manchas, riscos, oxidação ou rugosidade excessiva na superfície da peça.

## Ações Corretivas
1. Limpar a superfície com solvente adequado.
2. Se for apenas sujeira ou óleo, reinspecionar.
3. Se for oxidação leve, aplicar tratamento superficial (ex: fosfatização).
4. Se for risco profundo ou corrosão avançada, a peça deve ser descartada.
5. Registrar o código DEF-SUP.

## Causas Prováveis
- Armazenamento inadequado (umidade).
- Contaminação do banho químico.
