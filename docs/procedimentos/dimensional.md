# Procedimento: Desvio Dimensional

## Identificação
O desvio dimensional ocorre quando a peça não atende às tolerâncias especificadas no desenho técnico.

## Ações Corretivas
1. Medir a peça com paquímetro calibrado.
2. Se o desvio estiver entre 0,1mm e 0,5mm, encaminhar para retrabalho na usinagem.
3. Se o desvio for superior a 0,5mm, a peça deve ser descartada.
4. Notificar o operador da máquina para verificar a calibração das ferramentas.

## Causas Prováveis
- Desgaste da ferramenta de corte.
- Desalinhamento da máquina.
