# Procedimento: Correção de Trincas

## Identificação
Trincas são fissuras lineares que comprometem a integridade estrutural da peça.

## Ações Corretivas
1. Isolar o lote afetado e notificar o supervisor de qualidade.
2. Se a trinca for superficial (menor que 2mm), realizar o rebarbamento e reinspecionar.
3. Se a trinca for profunda (maior que 2mm), a peça deve ser descartada (refugo).
4. Registrar a ocorrência no sistema com o código de defeito DEF-TRI.

## Causas Prováveis
- Fadiga do material devido a ciclos térmicos.
- Resfriamento inadequado no processo de fundição.
